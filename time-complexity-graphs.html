Algorithms / Big O notation

Time complexity, drawn.

Each graph shows how an algorithm's work grows as the input size n increases. Curves are normalized within each card so every growth pattern stays visible.

Quick reference

ComplexityGrowthTypical example
O(1)ConstantRead one array index
O(log n)Very slowBinary search
O(n)LinearOne loop through an array
O(n log n)LinearithmicEfficient comparison sorting
O(n^2), O(n^3)PolynomialTwo or three nested loops
O(2^n)ExponentialNaive recursive Fibonacci
O(n!)FactorialTry every permutation

Big O describes an upper-bound growth trend. Constants and smaller terms are ignored as n becomes large.
