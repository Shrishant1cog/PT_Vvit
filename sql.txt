SQL PRACTICE NOTES
==================


1. CREATE TABLE
---------------

The CREATE TABLE statement is used to create a new table
with specified columns and data types.

Example:

CREATE TABLE emp (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    age INT,
    salary INT
);


EMPLOYEE TABLE STRUCTURE
------------------------

id      -> INT          -> Unique employee ID
name    -> VARCHAR(100) -> Employee name
age     -> INT          -> Employee age
salary  -> INT          -> Employee salary

3. SELECT
---------

The SELECT statement is used to retrieve data from a table.


Display all employees:

SELECT *
FROM emp;


Display specific columns:

SELECT name, salary
FROM emp;


--------------------------------------------------

4. WHERE CLAUSE
---------------

The WHERE clause is used to filter records based on
a specified condition.


Example:

SELECT *
FROM emp
WHERE age > 25;


This returns employees whose age is greater than 25.


COMMON COMPARISON OPERATORS
---------------------------

=      -> Equal to
>      -> Greater than
<      -> Less than
>=     -> Greater than or equal to
<=     -> Less than or equal to
<>     -> Not equal to


Example:

SELECT *
FROM emp
WHERE salary > 50000;


--------------------------------------------------

5. STUDENT TABLE
----------------

Create a student table:

CREATE TABLE stud (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    usn VARCHAR(50),
    number VARCHAR(20)
);


STUDENT TABLE STRUCTURE
-----------------------

id      -> INT           -> Unique student ID
name    -> VARCHAR(100)  -> Student name
usn     -> VARCHAR(50)   -> University/college registration number
number  -> VARCHAR(20)   -> Student contact number


IMPORTANT:

Phone numbers are usually stored as VARCHAR instead of INT.

Reason:

- Phone numbers can contain country codes.
- Phone numbers can start with 0.
- Phone numbers may contain +, -, spaces, etc.
- We normally do not perform mathematical operations on phone numbers.


--------------------------------------------------

6. DELETE
---------

The DELETE statement is used to remove records from a table.


Delete one employee:

DELETE FROM emp
WHERE id = 5;


Delete one student:

DELETE FROM stud
WHERE id = 5;


IMPORTANT:

The WHERE clause specifies which records should be deleted.


WARNING:

DELETE FROM emp;

This deletes ALL records from the emp table.

Always check the WHERE condition before executing DELETE.


--------------------------------------------------

7. DROP TABLE
-------------

DROP TABLE permanently removes the table and its data.


Example:

DROP TABLE emp;


After this command:

- The emp table is removed.
- The data inside the table is removed.
- The table structure is removed.


DELETE vs DROP
--------------

DELETE:
-> Removes records/rows
-> Table remains

DROP TABLE:
-> Removes the entire table
-> Table structure is also removed


Example:

DELETE FROM emp
WHERE id = 5;


Only employee with id = 5 is deleted.


DROP TABLE emp;


The entire emp table is deleted.

9. NOT OPERATOR
---------------

The NOT operator reverses a condition.


Example:

SELECT *
FROM customers
WHERE NOT (country = 'USA');


This selects customers whose country is NOT USA.


Equivalent query:

SELECT *
FROM customers
WHERE country <> 'USA';


NOT:
-> Reverses a condition


--------------------------------------------------

10. OR OPERATOR
---------------

The OR operator returns records when at least one
condition is true.


Example:

SELECT *
FROM customers
WHERE country = 'USA'
   OR country = 'UK';


This selects customers from either:

USA
OR
UK


Example:

SELECT *
FROM customers
WHERE country = 'USA'
   OR first_name = 'John';


A record is returned if either condition is true.


--------------------------------------------------

11. AND OPERATOR
----------------

The AND operator returns records only when ALL conditions
are true.


Example:

SELECT *
FROM customers
WHERE country = 'USA'
  AND first_name = 'John';


Both conditions must be true:

country = USA
AND
first_name = John


Example:

SELECT *
FROM emp
WHERE age > 25
  AND salary > 50000;


This returns employees who:

- Are older than 25
- AND have a salary greater than 50000


--------------------------------------------------

12. DELETE FROM CUSTOMERS
-------------------------

To delete a specific customer:

DELETE FROM customers
WHERE first_name = 'Betty';


To verify the remaining records:

SELECT *
FROM customers;


IMPORTANT:

If multiple customers have the first name 'Betty',
all matching records may be deleted.

Using a unique ID is usually safer:

DELETE FROM customers
WHERE id = 5;

17. UPDATE STATEMENT
--------------------

The UPDATE statement is used to modify existing records.

Example:

UPDATE emp
SET salary = 90000
WHERE id = 2;


This changes the salary of employee with id = 2.


Update multiple columns:

UPDATE emp
SET age = 30,
    salary = 60000
WHERE id = 8;


IMPORTANT:

Always use WHERE when you want to update specific records.

Without WHERE:

UPDATE emp
SET salary = 90000;

This may update EVERY employee.


--------------------------------------------------

18. ALTER TABLE
---------------

ALTER TABLE is used to modify the structure of an
existing table.


Add a column:

ALTER TABLE emp
ADD department VARCHAR(50);


Now the emp table has an additional column:

department


--------------------------------------------------

19. DISTINCT
------------

DISTINCT is used to remove duplicate values from
the result.


Example:

SELECT DISTINCT country
FROM customers;


This returns each country only once.


--------------------------------------------------

20. ORDER BY
------------

ORDER BY is used to sort the result.


Ascending order:

SELECT *
FROM emp
ORDER BY salary ASC;


Descending order:

SELECT *
FROM emp
ORDER BY salary DESC;


ASC:
-> Ascending order


DESC:
-> Descending order


--------------------------------------------------

21. LIMIT
---------

LIMIT is used to restrict the number of records returned.

Example:

SELECT *
FROM emp
LIMIT 5;


This returns only 5 records.

NOTE:

LIMIT syntax is supported by databases such as MySQL
and PostgreSQL. Other database systems may use different
syntax.


--------------------------------------------------

22. COUNT()
-----------

COUNT() is used to count records.


Example:

SELECT COUNT(*)
FROM emp;


This returns the number of employees.


Example:

SELECT COUNT(*)
FROM emp
WHERE age > 25;


This counts employees whose age is greater than 25.


--------------------------------------------------

23. MIN(), MAX(), AVG(), SUM()
------------------------------

MIN():
Returns the smallest value.

SELECT MIN(salary)
FROM emp;


MAX():
Returns the largest value.

SELECT MAX(salary)
FROM emp;


AVG():
Returns the average value.

SELECT AVG(salary)
FROM emp;


SUM():
Returns the total value.

SELECT SUM(salary)
FROM emp;


--------------------------------------------------

24. SQL CLAUSE ORDER
--------------------

A basic SELECT query is commonly written in this order:

SELECT
FROM
WHERE
GROUP BY
HAVING
ORDER BY
LIMIT


Example:

SELECT department, AVG(salary)
FROM emp
WHERE age > 25
GROUP BY department
HAVING AVG(salary) > 50000
ORDER BY AVG(salary) DESC
LIMIT 5;


Do not confuse the written order with the database's
logical query-processing order.

==================================================
IMPORTANT DIFFERENCES
==================================================

DELETE vs TRUNCATE vs DROP

DELETE:
-> Deletes selected rows
-> WHERE can be used
-> Table remains

TRUNCATE:
-> Deletes all rows
-> Table remains
-> WHERE cannot be used

DROP:
-> Deletes the entire table
-> Structure is also removed


WHERE vs HAVING

WHERE:
-> Filters rows before grouping

HAVING:
-> Filters groups after GROUP BY


AND vs OR

AND:
-> All conditions must be true

OR:
-> At least one condition must be true


PRIMARY KEY

-> Uniquely identifies each row
-> Cannot be NULL
-> Values must be unique
